# Benchmark Reports

This directory holds JSON benchmark outputs from `tests/scale/`. They
are intentionally version-controlled so release reviewers can see
quality + cost + throughput drift across releases.

## What's in here

| Filename pattern | Source | Contents |
|---|---|---|
| `live-*.json` | `tests/scale/test_programs_live.py` | Outputs from live-LLM Program tests against real provider APIs (`gpt-5.4-nano` by default). Documents, total token counts, total cost in USD, elapsed wall-clock, and a **100-character summary head** for sanity-check readability. |
| `corpus-qa-*.{json,md}` | (pre-existing) Corpus QA calibration | Question-answering accuracy + cost trace over a 30-doc QA corpus. |
| `long-doc-calibration-*.{json,md}` | (pre-existing) Long-doc calibration | Long-document grounding / chunking calibration runs. |

## Fixture / corpus provenance

The live-LLM tests in this directory exercise three external
corpora, none of which is committed in this repo:

1. **`usc.jsonl`** — every section of the United States Code. Sourced
   from the `alea-institute/kl3m-data-usc` Hugging Face dataset; the
   underlying records are works of the U.S. federal government and
   are **in the public domain** under 17 U.S.C. § 105.
2. **`edgar_agreements.jsonl`** — 200 SEC EDGAR contract filings.
   Sourced from `alea-institute/kl3m-data-edgar-agreements`. The
   underlying filings are **public submissions** to the SEC; the
   `alea-institute` redistribution license terms govern the
   collection.
3. **`patents.jsonl`** — 200 U.S. patents. Sourced from
   `alea-institute/kl3m-sft-patents`. Patent documents are
   **published by the USPTO and are in the public domain**.

The corpora are downloaded on demand by
`kaos-nlp-core/tests/fixtures/download_hf_fixtures.py` — they are
**not** committed under `tests/fixtures/` in any of the per-package
repos (size + provenance reasons).

## What the benchmark JSONs contain

The `live-*.json` files include short LLM-generated summary / output
samples. These samples are:

- **Generated by an LLM** (default `gpt-5.4-nano`) over the
  public-domain or publicly-filed records above.
- **Truncated to 100 characters** as of the P0/P1 audit (previously
  300; reduced to lower the risk of editorial drift about real
  third-party entities named in real public filings, e.g. Ameri
  Metro Infrastructure Cryptocurrency Inc. or Jewel's Real Estate
  1086 MASTER LLLP in EDGAR filings).
- Reproducible: re-running `tests/scale/test_programs_live.py`
  with the same model + seed will regenerate roughly equivalent
  samples (LLMs are not bitwise deterministic; samples reflect the
  spirit not the letter of any one run).

**These summary heads are not editorial commentary about the named
entities. They are mechanical outputs of a model over a public
filing, included only so a release reviewer can eyeball coherence.**
If you are auditing the model's treatment of a specific filing,
read the verbatim source from `alea-institute/kl3m-data-*`, not
from this directory.

## Regenerating

```bash
# Refresh the live-LLM benchmarks (requires API keys + fixtures):
KAOS_NLP_SCALE_FIXTURES=/path/to/usc/edgar/patents \
  uv run pytest tests/scale/test_programs_live.py -v -m live

# Skip the report side-channel (useful in CI):
KAOS_LLM_CORE_SCALE_NO_REPORT=1 \
  uv run pytest tests/scale/test_programs_live.py -m live
```

Cost ceiling on the default cheapest-model path is approximately
**$0.01 per full live-test sweep** at `gpt-5.4-nano` rates
($0.10/M input + $0.40/M output). Override with
`KAOS_LLM_CORE_SCALE_MODEL` for a different provider.
